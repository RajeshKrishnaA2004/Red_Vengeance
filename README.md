## 🎮 About the Game

**Red Vengeance** is a side-scrolling action platformer developed in **Unity** using **C#**.

Fight through dangerous levels filled with enemies, obstacles, and platforming challenges while mastering movement and combat mechanics. The game focuses on smooth controls, responsive gameplay, and engaging level progression.

---

## ✨ Features

- 🎮 Smooth player movement
- ⚔️ Melee combat system
- 👾 Enemy AI
- ❤️ Health system
- 🏃 Running & Jumping mechanics
- 💀 Player death and respawn
- 🗺️ Multiple handcrafted levels
- 🎥 Gameplay demonstrations
- 🎨 Custom sprites and animations

## 🎯 Gameplay

The player must:

- Explore dangerous environments
- Defeat enemies
- Avoid traps
- Complete each level
- Reach the final objective

Each level introduces new challenges requiring both combat skills and precise platforming.

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/RajeshKrishnaA2004/Red_Vengeance.git
```

2. Open the project using **Unity Hub**

3. Open the main scene inside the **Scenes** folder.

4. Press **Play**.

---

## 🎮 Controls

| Action | Key |
|---------|-----|
| Move Left | A |
| Move Right | D |
| Jump | Space |
| Attack | Left Mouse Button |
| Pause | Esc |
